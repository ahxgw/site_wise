Context

amazon.fr is Amazon's French storefront. Amazon announced it on 29 August 2000 as its third European site, with operations in Guyancourt and a distribution centre in Orléans, and opened third-party Marketplace selling in November 2003. By EU DSA recipients it is Amazon's second-largest EU market after Germany, and Médiamétrie ranks it France's most-visited e-commerce site (Verified Metrics). Amazon's 10-K does not break out French sales; France sits inside "Rest of world". For an index builder, France adds two things the amazon.de and amazon.co.uk profiles lacked. The first is a statutory €3 shipping floor on new books, which the Conseil d'État upheld in May 2026. The second is a crawl wall that, on today's probe, closed before any product page loaded, so the page-level sample here comes from the Internet Archive.

Retrieval Notes (site-specific deltas)

Only where amazon.fr differs from the default assumptions and from the .de and .co.uk profiles.

The crawl budget can be zero

On .de the captcha arrived after ~14 requests and on .co.uk after ~11. Here it was already in place on request 1, and it applied to .de too (Probe Log). A crawler cannot assume a fresh per-session allowance. Budget per exit IP across all Amazon stores, check a detail page before scheduling work, and treat a 3,815-byte 200 as a block. The fallback for page structure is the Internet Archive, which held 200 captures of all three sampled ASINs.

Archive captures carry someone else's fetch context

Wayback served an unprefixed bestsellers URL in English (lang="en-gb") and one detail page with countryCode=GB. Archived Amazon pages therefore reflect the archiver's locale and delivery address, not the French default. Store lang, countryCode and currencyOfPreference with every archived record, and never treat an archive's offer fields as FR-delivery truth.

Books need a regulatory price model

New books carry a statutory €3 shipping floor below €35, except for pickup in shops that sell books (Verified Metrics). A price-tracking index should segment Books from the other 38 indexes and record delivery mode with the shipping fee. A free-shipping flag on a sub-€35 book is a compliance signal, not a promotion. ForeignBooks is its own index and should not inherit French book rules blindly.

Faceted search is pre-pruned

The */s?k=*&rh=n*p_*p_*p_ rule caps crawlable search at two attribute refinements, a pattern shared with .it and .es. A discovery crawler that walks facets should stop at depth two. Deeper combinations are both disallowed and, given the captcha, unaffordable. Seed discovery from bestsellers and the API instead.

Review provenance is Francophone-plus

Belgian (now its own store), Canadian (Québec) and Dutch reviews appear alongside Spanish and UK ones. Key reviews on (source marketplace, review ID). Expect French-language text from .com.be and .ca, which a language-ID step will not separate from French-store reviews. Only the origin line does, and it has two label variants ("Avis laissé en …" and "Commenté en …").

Different review hook

The archived FR pages use data-hook="review-body", while .de's profile counted reviewText. An extractor written for one store will silently return zero reviews on another. Match both hooks, and alert on a store-wide zero.

Indexing Plan

  • Retrieval unit: product = (FR, ASIN). Reviews are child documents keyed (source marketplace, review ID). Offers are sub-records keyed (ASIN, seller, delivery country, delivery mode); delivery mode is needed for the book shipping floor.
  • Join keys: the ASIN from the path, never the slugged canonical; marketplaceId=A13V1IB3VIYZZH to validate the store on archived captures; media ID for images; manifest URL for video.
  • Ingestion paths, ranked: 1) The Creators API for catalogue, browse nodes and EUR offers, which is the only path that worked for us today. 2) Wayback CDX latest-200 plus id_ for structure, review samples and history, with the fetch context recorded. 3) A slow live /dp/ crawl from French exits with clean reputation, gated by a detail-page health check.
  • Recrawl cadence: offers daily via the API, with book shipping fees stored per delivery mode; velocity badges weekly to match their window; reviews monthly.
  • Derivatives: a DOM extractor matching both review hooks; a review-origin parser for both label variants; a books-compliance flag (shipping fee by delivery mode and order value); HLS keyframe and ASR extraction.
  • Demo to build: an "archive versus live context" diff. For a fixed ASIN panel, compare Wayback captures with API Offers V2 and flag the fields where the archive's countryCode or lang made the snapshot disagree with France.

Risks to the Index

  • inferred Live access can be lost before the first request. Basis: request 1 to .fr and the first request to .de both returned the captcha (Probe Log). The block follows exit-IP reputation across stores, not session behaviour. Capacity planning cannot rely on a per-session request allowance.
  • Book-shipping rules are settled but still being enforced. The Conseil d'État upheld the floor on 2026-05-13, and Amazon changed locker delivery only after that (Livres Hebdo). Shipping-fee fields on books changed in September 2026, so historical book-offer series need a regime break at that date.
  • inferred Archive-based coverage is biased toward popular ASINs. Basis: CDX found 200 captures for the bestseller ASINs we tried, but the oldest was from 2022 and the 2026-10-05 capture had no review bodies. Archive depth tracks external link popularity, not catalogue breadth.
  • The in-page API pointer is still stale. The captcha comment still names the PA-API page on partenaires.amazon.fr, which was retired in favour of the Creators API (notice).

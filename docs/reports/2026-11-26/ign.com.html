Context

IGN publishes games, movie and TV news, reviews, video guides and a large game wiki. Its ads.txt names ziffdavis.com as owner, and the robots.txt header is a Ziff Davis notice that prohibits text and data mining, AI training and retrieval, dataset creation and commercial use without written permission. Ziff Davis reports no IGN revenue line; the group earns from advertising, affiliate commerce and subscriptions. For an index builder IGN is unusually well structured: five typed sitemap families, a full-body RSS feed, and a game-object graph that ties articles, videos and wiki pages together. The constraint is legal rather than technical. The open surface is large, but the stated reuse terms are closed.

Retrieval Notes (site-specific deltas)

Identifier & dedup

Slugs are the public key; the feed guid is a UUID, which gives a second stable ID per article. A review slug can carry a numeric suffix (lego-godzilla-review-21375). Homepage canonical is https://www.ign.com; regional hreflang points to /au, /ca and me.ign.com.

Retrieval unit

Article with its linked game object. A review or guide is only useful attached to the game it covers, so index the article and carry the object slug.

Cross-modal joins

Article payload primaryObject and objects join to /games/{slug}; video pages share the slug namespace of the object families; wiki sitemaps are named by game slug (sitemap-wikis-{game}.xml). Slugs are stable until an editorial rename; renames are untested.

Authoritative content field

JSON-LD headline and dateModified over the sitemap lastmod; feed content:encoded over scraped DOM, which includes ad slots. Video descriptions hold chapter timestamps that are usable as segment boundaries.

Freshness & recrawl

Edge cache is 10 seconds on HTML. Archive-year sitemaps get lastmod bumps months later, so a yearly file's date cannot say which URLs changed; compare per-URL lastmod inside it.

Quality & spam

The newest 2026 sitemap entries are dominated by Black Friday deal pages (for example Proton VPN, T-Mobile, Lenovo), so commerce content has a short useful life. Basis: five of the first nine URLs in sitemap-articles-2026 carry deal or gift-guide slugs.

Internal vs external search

/search is disallowed in robots.txt, so site search is not a legitimate ingestion path; the sitemaps replace it.

User query profile

Slugs suggest queries like "how to get all 100 Gold Skulltulas", walkthrough and code lookups, release schedules and reviews. Basis: video slugs and wiki Allow lines name guides, codes and walkthroughs.

Indexing Plan

  • Retrieval unit: article (review, news, guide) keyed by slug with the game object attached; video as a separate unit with chapter segments; wiki page as a third.
  • Primary keys & joins: slug per type, feed guid for articles, primaryObject slug to game object, author URL to contributor.
  • Ingestion paths, ranked: 1) a written license from Ziff Davis, which is the only route the robots header leaves open for AI or commercial use; no cost known. 2) The articles feed plus news sitemap for incremental discovery of new items, 20 items per page and 49 news URLs; coverage is recent only. 3) The 31 yearly article sitemaps for a full URL inventory (479K) without fetching pages. 4) Video and object sitemaps for 56.6K and 135K metadata rows, which carry titles and descriptions inline.
  • Recrawl cadence: news and deal pages hourly via the news sitemap; reviews and guides weekly; game objects daily by lastmod; archive years monthly by per-URL lastmod.
  • Derivatives to generate: embeddings from title plus description; chapter-level video segments from sitemap descriptions; ASR only if licensed, since captions are null on the sampled video.
  • Demo to build: a game-centric index built only from sitemap metadata (479K article titles via slugs, 135K object rows) that links out to ign.com. It tests whether the object graph can answer "everything about game X" without storing any body text.

Risks to the Index

  • The Ziff Davis notice prohibits AI, retrieval and commercial use without written permission. Even the sitemap and feed paths are "automated means" under its own wording, so any production use needs a license first.
  • Edge behavior is uneven: ClaudeBot gets 200 despite a Disallow, GPTBot gets 403, and a Googlebot string gets 418. Enforcement could tighten to match robots.txt at any time.
  • The robots file is mutable and long (191 UA lines); the 130 Allow exceptions look like campaign pages, so the allowed set will drift.
  • The GraphQL host answers anonymously today, but its CORS headers name secret and Postgres routing headers, so it is internal plumbing that can be locked without notice.

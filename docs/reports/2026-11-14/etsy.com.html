Context

Etsy is a two-sided marketplace for handmade, vintage (20+ years old) and craft-supply goods. Independent sellers list items, and Etsy earns transaction, listing and payment fees plus seller-paid ads. With Depop sold to eBay on 2026-07-30, the company is down to the Etsy marketplace and Reverb (see the eBay report). The index-relevant object is the listing. It is a seller-written product page with up to about ten photos, an optional video, variations, a buyer-taxonomy path, and reviews. Listings are long-tail and one of a kind, so the text is SEO keyword soup and the photos carry most of the signal. Etsy now runs two access tracks. Bots get a DataDome wall on every HTML path. Its sitemaps were withdrawn from robots.txt in early 2026 and now 403 at origin. AI assistants, by contrast, get a curated llms.txt that routes them to search-like /market/{keyword} pages. The developer API is keyed, and its terms rule out building a third-party index.

Retrieval Notes (site-specific deltas)

Only where etsy.com departs from the default platform assumptions.

Two contradictory gates

robots.txt has a single * group with no AI carve-outs, and llms.txt says its listed URLs are fetchable. In practice DataDome 403s every HTML path, the llms.txt example included, for a polite non-browser client. The rulebook describes a policy that the edge does not enforce the same way. Budget for "no first-party HTML" unless the client is one of the partners Etsy whitelists.

Sitemaps withdrawn, tiering revealed

The January 2026 sitemap families show how Etsy curates for SEO. Listings and shops were split by seller tier (vip, power, top, star, local), plus stash, market, taxonomy and blocklist. The sitemaps have been delisted since spring and the origin 403s them, so no public census path is left.

Identifiers & joins

listing_id is the key: it is in the URL, equals the JSON-LD sku, and is the API path. The slug after it is cosmetic. Strip locale prefixes and utm_*, which share links append (seen in Wayback). shop_id and user_id join to shops and reviews. Image URLs embed {shop/owner id}/r/il/{hash}/{image_id}. gtin is "n/a", so there is no product-level dedup across sellers.

Image is the authoritative field

Titles are comma-joined keyword lists ("…Necklace, Bridesmaid Necklace, Daily Pearl Necklace, Bridesmaid Gift"), and the tags repeat them. Etsy already writes machine captions into ImageObject.description ("May include: …"). Index image embeddings first and treat title keywords as noisy facets. aggregateRating on a listing is the shop's score, so do not use it as an item rating.

Image CDN dates and dedups for free

i.etsystatic.com is open GCS-backed storage. A HEAD request returns the upload time (x-goog-generation) and an MD5. Together they date a listing's photos without touching the walled page, and they catch the same photo reused across shops, a common reseller pattern.

Assistant-first discovery

Etsy steers AI agents to generated /market/ pages tagged source=llms.txt, which it can attribute and measure. The 10-K lists "agentic search integration" among its marketing channels. For a third-party index this means the AI path is a referral surface, not a data feed.

Indexing Plan

  • Retrieval unit: the listing: title, description, tags, materials, taxonomy path, price and currency, shop, photos with captions and embeddings, video, and a review summary. The shop is a secondary unit.
  • Primary keys & joins: listing_id, shop_id, taxonomy_id, listing_image_id plus the image MD5.
  • Ingestion paths, ranked: 1) A written data agreement with Etsy. The API terms bar search and ML use otherwise, so this is the only clean full-coverage path. 2) Open API v3 for display-only features within the 6-hour freshness rule (the keyword search returns at most 100 per page by offset). 3) Archived HTML (Wayback, Common Crawl) for JSON-LD on popular listings, as historical snapshots only. 4) The image CDN for media whose URLs come from 2 or 3. Never fight DataDome.
  • Recrawl cadence: price and availability at most 6 hours stale for anything displayed. Listing text weekly. Reviews daily for tracked shops. Taxonomy monthly.
  • Derivatives to generate: image embeddings and dedup clusters keyed by MD5 and perceptual hash, normalized attributes from who_made/when_made/materials, and title de-keywording into canonical product phrases.
  • Demo to build: a listing-age estimator that takes an image URL from an archived category page, HEADs it, and plots upload time against listing_id to build an ID→date curve, with no etsy.com HTML fetched.

Risks to the Index

  • Contractual exclusion. The 2026-08-18 API terms name analytics, ML, AI training and licensing as barred uses, and they bar scraping the site (Verified Metrics). A search index built on API data needs explicit written permission.
  • inferred Open side doors may close. Basis: the sitemaps went from 461 robots.txt lines (January) to none (April) to an origin 403 (Probe Log). The OpenAPI JSON and the image CDN are the remaining unwalled first-party surfaces.
  • Freshness liability. The 6-hour display rule makes any cached price a terms violation within hours, so price fields cannot be served from a weekly crawl.

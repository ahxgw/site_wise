Context

rule34.xxx is an anonymous, user-uploaded imageboard ("booru") for explicit fan art of characters from games, anime, cartoons and other media. Every post is an image, GIF or video file plus a flat list of community-maintained tags: characters, copyrights, artists, and many descriptive tags. Search is the product, and a tag query is the whole query language. The operator is unnamed. TorrentFreak described the site in 2021 as having about 100M monthly visitors, and as fighting a Google delisting of its homepage that it blamed on bogus complaints. Revenue is display advertising plus a merch store. The API terms ban ads and paywalls on any third party that serves the site's files. For an index builder it is the largest public tag-labelled adult illustration corpus: millions of images with dense human tags and live per-tag counts. But every bulk path is now closed or keyed, and the corpus mixes in AI output and real-person content that need filtering.

Retrieval Notes (site-specific deltas)

Only where rule34.xxx differs from the default platform assumptions.

No crawler track at all

The default picture has an SEO sliver for approved crawlers. Here the CAPTCHA page is served to spoofed Googlebot and bingbot alike, robots.txt lists no sitemap, and the API page says Google is not ranking the main host. inferred Search engines see little of the post corpus. Basis: the API-page banner about Google, no Sitemap: line, and a sitemap URL that returns the CAPTCHA. The only designed machine path is the keyed DAPI.

The opposite of an AI block

robots.txt names no AI crawler and disallows only the removal form. The terms that matter live on the API page: one key per person, no ads, no paywalls. Policy is enforced by keys and CAPTCHA, not by robots, so robots-based compliance tooling reads this site as fully open when it is not.

Tags are the schema

There is no title, caption or description: the tag set is the document. Tags are underscore-joined, lower-case, and disambiguated with a parenthetical qualifier such as natsuki_(doki_doki_literature_club). That makes the corpus a ready supervised dataset for image-to-tag retrieval, and the tag vocabulary is shared with other boorus. Normalize away the junk: autocomplete returned tags containing CR/LF and zero-count entries. Variant spellings coexist (absurd_res 1.03M vs absurdres 413K; ai_generated vs ai-generated), so the alias table is part of the index.

AI share is first-order

At least 3.55M posts are tagged ai_generated, plus 239K ai_assisted. For any image index that values human-made art, this is the most important filter on the site. The label is community-applied, so treat untagged recent posts as unknown rather than human-made.

Media on two networks

Images sit on Cloudflare hosts; video comes from two origin servers in the Netherlands with no CDN headers. Video fetch throughput and availability are governed by those origins, not Cloudflare. Plan per-host rate limits.

Indexing Plan

  • Retrieval unit: the post (file + tag set + rating + score + source URL), keyed by numeric post ID. Tag pages are derived listings, not units.
  • Primary keys & joins: post ID; file MD5 (booru convention, carried in file names) for cross-booru dedup; source URLs → artist pages on other platforms; character/copyright tags → franchise entities (for example, the pixpedia tag layer in the 2026-10-20 report).
  • Ingestion paths, ranked:
    1. A single DAPI key, or an "unlimited key" request framed as a public search project. Backfill by ID ranges at 1,000 posts per call: 10.55M posts ≥ 10.6K calls (calculated by Site Wise). Then poll by cid for edits and deleted=show for removals.
    2. Open autocomplete for a tag-count census and trend series. It needs no key, but it covers only the top 10 tags per prefix.
    3. Common Crawl captures of post pages for a key-free sample (coverage open).
  • Recrawl cadence: new posts continuously by ID; tag edits by cid daily; deletions daily (required); tag counts weekly.
  • Derivatives to generate: CLIP-style embeddings from previews; a tag alias/implication table; an AI-vs-human classifier trained on the ai_generated label; OCR for comics.
  • Demo to build: a key-free tag trend board. Poll autocomplete hourly for a fixed list of franchise and character tags, and chart per-tag growth and the AI-tag share over time.

Risks to the Index

  • Keyed and revocable: the DAPI is the only bulk path, with one key per person and the right to "disable or deny any key". No archive fallback exists, because Wayback excludes the domain.
  • Illegal and non-consensual content risk: the site has faced CSAM complaints from Russia's regulator and through Cloudflare (2021), and hosts 21K real_person posts. Drawn sexual depictions of minors are illegal in several jurisdictions. Any ingest needs hash matching (NCMEC/IWF-style lists), real-person exclusion, deletion-feed propagation and jurisdiction-aware filtering before anything is stored.
  • Copyright: uploads are third-party art of copyrighted characters, posted without a license grant. Store metadata and embeddings; display at most a linked thumbnail.
  • Display terms: the no-ads/no-paywall API rule rules out monetizing any surface that serves rule34 files.
  • Label noise: 2.39M tagme posts and community-applied AI tags limit tag-based filtering. Pair tags with classifiers.

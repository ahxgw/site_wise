Context

Flipkart is India's largest home-grown e-commerce marketplace: an online bookstore started in a Bengaluru flat in 2007 by Sachin Bansal and Binny Bansal, majority-acquired by Walmart in 2018, and re-domiciled to India in 2026 ahead of a planned FY27 listing. It earns marketplace commissions, seller services, advertising, and logistics fees through eKart, with quick commerce added via Flipkart Minutes. For an index builder Flipkart is the mirror image of Amazon. Amazon publishes no sitemap and bans AI crawlers by name; Flipkart publishes a nine-file sitemap tree covering roughly 83M canonical product URLs, stamps schema.org Product JSON-LD onto listings, refreshes its sitemap index daily — and names no AI crawler at all. Then it puts a reCAPTCHA Enterprise interstitial in front of every path on www, and its Terms of Use forbid any "page-scrape", "robot" or "spider". The catalog is mapped in public and gated in practice. inferred The crawl surface is built for allowlisted search engines, not for crawlers generally. Basis: robots.txt grants named Google agents unrestricted access and advertises nine sitemaps, while plain-UA requests to those same sitemap URLs return HTTP 403 reCAPTCHA (Probe Log).

Retrieval Notes (site-specific deltas)

Only where Flipkart differs from the default platform assumptions.

Identifier & dedup

Flipkart runs two product identifiers in parallel, published in different places. URLs and every sitemap entry key on the itm ID (/p/itm000439652e07f); JSON-LD sku and the affiliate API key on the PID (PJTHERJGTJQRRBT8), whose prefix encodes category (ACC, CAY, MSA). Nothing public maps them in bulk — you learn the pair only by fetching the page, so an index ingesting sitemaps and feeds together double-counts until it resolves this.

Retrieval unit

The product page, not the offer: no visible multi-seller offer array per listing, so product and offer collapse into one record. Specification lists carry the substantive text — titles are short and attribute-stuffed, descriptions are template prose built around the price.

Cross-modal joins

PID joins JSON-LD, feed, images and seller ratings; the itm ID joins sitemap and URL only. Image URLs embed the category slug plus a stable asset hash (…/pooja-thali-set/t/g/9/no-wa006-wraparts-original-imaherjgj8ezpzup.jpeg), usable as a dedup key across resized variants. Reviews join to product, not to a durable reviewer ID.

Authoritative content field

JSON-LD beats the rendered DOM: it types the actual selling price, availability, shipping rate and return window, where the page mixes MRP, discount and promotional "Buy at" copy a parser would fumble. The /hi/ variant translates chrome and attributes but leaves titles in English and mislabels itself lang="en-IN" — language detection cannot trust that attribute here.

Freshness & recrawl

The freshness signal is deliberately coarse: sitemap index entries are re-stamped daily, but child sitemaps carry no lastmod at all, so a moved timestamp says something changed among 22,901 products without saying which. Either re-fetch a whole child or drop crawl for the Delta Feed's version counter.

Quality & spam

The tail is commodity accessories: 7 of 10 randomly sampled products were phone cases, skins or handset spare parts, many near-identical listings from different micro-brands (dikro, jugga, flipcase, yapzone, nassion, fronk). Near-duplicate detection matters more than fake-review detection, and 8 of 10 had no rating at all, so quality priors cannot lean on ratings.

Internal vs external search

On-site search is closed to crawlers outright — /search?, /search-book? and /search.php? disallowed, along with ~20 facet parameters. Only product pages and curated browse/store/query-browse sitemaps are offered: Flipkart exports a catalog, not a query log.

Indexing Plan

  • Retrieval unit: product record keyed by PID, itm ID as secondary alias, specification list as primary text, price/stock as fast-refresh sub-fields.
  • Primary keys & joins: PID (JSON-LD sku or feed productId) is the spine; itm→PID table built during first fetch; image asset hash for media dedup; categoryPath for taxonomy.
  • Ingestion paths, ranked: 1) Affiliate Delta Feed per category — the only incremental path with a version counter, and needs no rendering. 2) Feed Download API zipped CSV for cold-start bulk. 3) Sitemap tree for discovery and coverage audit — free, unauthenticated, the only source enumerating all ~83.4M URLs. 4) Rendered fetch for JSON-LD fields the feed omits (aggregateRating, inline reviews, shipping and return policy) — wall-gated and expensive, so reserve it for a sample.
  • Recrawl cadence: Delta Feed daily per category; sitemap index diffed daily for new children; full child re-fetch only where the index lastmod moved; rendered re-fetch monthly on a stratified sample to keep coverage statistics honest.
  • Derivatives to generate: itm↔PID concordance, near-duplicate clustering over accessory listings (title + image hash), attribute normalisation across micro-brands, Hindi/English collapse via canonical.
  • Demo to build: a sitemap-only catalog profiler — walk the six index files, sample N children, report canonical-vs-duplicate split, category mix from URL slugs, and estimated live SKU count with confidence bounds, without ever touching a walled page.

Risks to the Index

  • The only documented API is unmaintained. Docs stamped "© Copyright 2015", unversioned Product APIs deprecated, and the sidebar's own "API Terms Of Use" link 404s (Probe Log). An index built on it has no maintained contract to point at.
  • robots.txt and the Terms of Use disagree. The permissive crawl policy is not a licence; the Terms forbid "page-scrape", "robot" and "spider" access outright. Following the Terms means treating the sitemap as a census instrument, not a fetch queue.
  • No AI-crawler policy means no grandfathered position. Since robots.txt names no AI agent today, Flipkart can add a blanket Disallow in a single deploy without contradicting any prior stance.
  • Ownership and disclosure are in motion. Re-domiciliation from Singapore to India is complete — eight Singapore entities merged into Flipkart Internet Private Limited, NCLT approval December 2025, announced March 2026 — with an IPO targeted for FY27 (Reuters via Yahoo Finance). A listing would replace estimate-only GMV with audited figures and add disclosure-driven constraints on data sharing.
  • Indian regulatory action targets marketplace structure. The CCI Director General's investigation report alleging competition-law violations was served on Flipkart subsidiaries September 13 2024, and the Directorate of Enforcement's FDI proceedings (notice July 2021, latest request April 2025) carry possible "share ownership restrictions" (Walmart FY2026 Form 10-K). Those remedies reach seller relationships and listing structure — exactly what the catalog encodes.
  • inferred The bot wall will tighten before the sitemap does. Basis: reCAPTCHA already covers every www path including /robots.txt, while the sitemap tree stays fully public and daily-refreshed — Flipkart defends fetch, not discovery (Probe Log).

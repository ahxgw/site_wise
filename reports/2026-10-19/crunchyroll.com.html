Context

Crunchyroll is Sony's anime streaming service. Founded in 2006 in San Francisco, it was bought from AT&T in August 2021 for $1.175B, and Funimation, Wakanim and VRV were folded into it in March 2022. The free ad-supported tier ended on 2025-12-31, so since 2026 every episode needs a paid Fan, Mega Fan or Ultimate Fan plan. Public comments were removed in July 2024. For an index builder, Crunchyroll is a licensed-video catalog. The useful objects are structured records: series, season and episode metadata, dub and sub language matrices, maturity descriptors, key art, and star ratings. The video, audio and subtitle files sit behind a paywall and DRM, so they are out of reach. The interesting fact is the access split: the HTML front end challenges every client, while the catalog JSON that the web app needs is served to an anonymous token.

Retrieval Notes (site-specific deltas)

Only where crunchyroll.com differs from the default platform assumptions.

The SEO track is closed to everyone, the API track is open to everyone

This inverts the default two-track split. robots.txt blocks no AI crawler and advertises sitemaps, but every UA, including Googlebot, is challenged on those sitemaps and on all pages. Meanwhile the catalog API answers an anonymous token without a challenge. inferred Verified search-engine IPs probably bypass the challenge. Basis: the Wayback crawler got a fully server-rendered series page with JSON-LD on 2026-09-27, while every UA from our IP was challenged. For an index, the API is both the more complete and the cheaper path: 23 calls list the whole catalog.

Identifier & dedup

GUIDs are 9–12 characters (G4PH0WJZN, GMTE00251166, GT00383995); the prefix reflects the source system. Every audio dub is its own episode GUID and /watch/ URL, so the sitemap's ~101K episode URLs collapse to 47K episodes. Group by versions[], keep the original: true GUID as canonical, and attach dubs as language variants. identifier (series|season|E{n}) is a stable composite key. external_id (SRZ.272111, EPI.942493) carries the legacy pre-2022 numeric ID.

Authoritative content field

Use the API record. The HTML meta description is a single boilerplate paragraph ("Stream X on Crunchyroll and experience…") repeated on every series. The JSON-LD name is prefixed with "Watch". Only the API description and episode title carry real text. Dub seasons are separate season objects whose titles end in "(English Dub)" or, on bad data, "(undefined Dub)". Strip that suffix before matching.

Cross-modal joins

Series GUID → seasons → episodes → versions[].media_guid (the stream key, unusable without a subscription). Art joins by the T{id} key-art ID. linked_guid on series links pre-merger Funimation and Crunchyroll records. Outside joins go by title plus series_launch_year to AniList, MyAnimeList and Wikidata. Crunchyroll exposes no external entity IDs.

Freshness & recrawl

No lastmod anywhere. Each simulcast season adds about 50–60 titles (fall 2026: 51; summer 2026: 59) and weekly episodes. The anonymous token is pinned to the requester's country (US here), and eligible_region is per episode, so availability is regional. Licenses expire: 44 titles are already unavailable, and their records persist as tombstones.

Mature content gating

The anonymous token is maturity M2, yet browse still returns 84 M3 titles flagged mature_blocked: true. Metadata is visible; playback would not be. Carry content_descriptors (Violence, Nudity, Sexual Violence and others) into the index for safe-search filtering.

Indexing Plan

  • Retrieval unit: one canonical episode, carrying its series and season context, title, synopsis, air date, runtime, original audio, dub language set, subtitle locales, maturity descriptors and a 1920×1080 thumbnail. Titles are a second unit with synopsis, genres, launch year, key art and the rating histogram.
  • Primary keys & joins: series, season and episode GUIDs; the identifier composite; versions[].guid for dub URLs; the key-art T{id}; title plus year for external anime databases.
  • Ingestion paths, ranked:
    1. Anonymous beta-api: browse (23 calls), then seasons and episodes (about 5.2K calls), at 1 req/s, which takes about 90 minutes. The coverage ceiling is one country per egress IP.
    2. Wayback id_ of the sitemaps for URL lists and news articles, which is the only non-API path to news. The latest captures are from May 2026 and some come back empty.
    3. Repeat path 1 from egress points in other countries to build the per-region availability matrix.
  • Recrawl cadence: browse daily during a season (new titles, last_public). Fetch the current season's episodes weekly and ratings weekly for the top 200 titles. Re-sweep the back catalog monthly to catch license expiries.
  • Derivatives to generate: image embeddings of key art and episode thumbnails, a normalized genre and demographic set from tenant_categories, a dub-availability facet, and entity links to AniList and Wikidata. No ASR or OCR: the source media is not accessible.
  • Demo to build: "where can I watch X dubbed in Y": answer language and dub availability queries from the version and locale matrix, which no public search engine exposes at episode level.

Risks to the Index

  • Undocumented API: beta-api and the cr_web client are internal web-app infrastructure with no published terms for third-party use. The anonymous grant could be closed or challenged at any time, as already happened on www.
  • Region-scoped truth: the token carries the requester's country, so one crawl shows one region's catalog. Treating it as global misstates availability.
  • License churn: titles go unavailable when licenses lapse. An index must keep tombstones and stop linking to them.
  • Sitemap blind spot: the advertised sitemaps are challenged, and the Wayback copies are months old and partly empty, so a sitemap-first crawler would undercount the catalog.

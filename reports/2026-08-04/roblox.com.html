roblox.com

Roblox blocks no AI crawler and serves open unauthenticated APIs, then forbids machine-learning use by contract. The gate is legal, not technical.

Gaming / UGC Platform NYSE: RBLX Open API, closed licence

Evidence: verified inferred (must state basis) open — conventions in the methodology.

Context

Roblox Corporation runs a user-generated 3D games platform: creators build "experiences" in Roblox Studio, players buy Robux, and Roblox pays creators back in fiat through the Developer Exchange — $363M of a $1,469M quarter. For an index builder it is the mirror image of a paywalled publisher. Its robots.txt names zero AI crawlers, it publishes no llms.txt, and dozens of JSON endpoints across the subdomains below answer 200 with no auth — Roblox's own docs mark them CookieNone. Raw image and audio assets download unauthenticated at 3,000 requests/minute. Yet the Terms of Use forbid accessing the Services "for the purpose of using Virtual Content in connection with the training, development, or use of machine learning models or artificial intelligence," and creators grant that ML-training licence to Roblox alone. inferred The contract, not the infrastructure, is the wall. Basis: every API response carries x-terms-message: Terms apply https://rblx.co/TOU. while the same hosts return no robots.txt at all (Probe Log).

Retrieval Notes (site-specific deltas)

Only where Roblox differs from the default platform assumptions.

Identifier & dedup

Two ID spaces, easy to confuse and not interchangeable. Every URL and sitemap entry carries a placeId; every metadata API keys on universeId. A universe owns many places, so the URL identifies a room and the API identifies the product. No bulk mapping exists — each placeId costs one places/{id}/universe call. The slug is decorative (/games/2753915549/anything resolves), so the placeId alone is the dedup key. Locale prefixes multiply each object 15×; strip them before ingest.

Retrieval unit

The universe, not the page. The page is a launcher; nothing a user plays is in the HTML. The document worth indexing is a composite the site never serves as one object: description + genre tree + creator + votes + screenshots + badges, from five endpoints. Badges are the nearest thing to a table of contents for gameplay — one named "Third Sea" with 94.5M awards describes progression no crawl can reach.

Cross-modal joins

Unusually clean, because everything is an integer asset ID: universeId → rootPlaceId → imageId[] → signed CDN URL, with creator.id + creator.type joining to the users or groups endpoint. The one unstable link is the thumbnail URL, which embeds an expiring signature — so the durable key is the imageId.

Authoritative content field

The API description and the page meta description disagree by design. The API returns creator text — patch notes, fruit spawn timers, anti-exploit warnings; the meta description is Roblox marketing copy ("Level up in this anime RPG fighting game…"). Creator text is the retrieval signal, meta text the snippet. And aggregateRating is not a rating: it is the up/down tally rescaled to 0–100.

Freshness & recrawl

The sitemap is useless as a change signal: zero lastmod, and its membership is itself the volatile part — a top-10,000 popularity snapshot, so today's list is a ranking, not a corpus. Poll the sitemap for entry and exit from the head, and updated per universe for content change. At 66% weekly churn, a monthly recrawl is a stale index.

Quality & spam

Titles are optimised for a child's search box, not a semantic one: the sample holds four near-identical "Would You Rather … Tower" variants and strings like "this awesome game". Cloning is endemic and now machine-assisted at 60,000 generated 3D assets per day. Text similarity will under-separate distinct experiences; the discriminating features are numeric — visits, concurrent players, badge award curves — not lexical.

Search demand & query profile

Roblox treats discovery as its own algorithm's job and told shareholders so: a Recommended-For-You change deliberately traded near-term monetisation for retention, and moved the bookings number. External search is not the demand channel — which explains why a top-50 site publishes 10,000 URLs and shows no sign of caring. What does arrive is navigational and title-shaped; the unmet classes are attribute-shaped ("obby games for 6 year olds"), which the site's own genre_l2 covers for only 68% of experiences.

Indexing Plan

  • Retrieval unit: the universe as a composite document — description, genre tree, creator, vote tally, badges, screenshots — with the rootPlace URL as canonical address and each screenshot an attached media child.
  • Primary keys & joins: universeId as document key; placeId as URL alias (many-to-one); creator.type + creator.id for the author join; imageId — never the signed URL — for media.
  • Ingestion paths, ranked: 1) The unauthenticated read APIs — complete fields, no key, but exactly the access ToU (d) prohibits, making this a legal decision before a technical one. 2) Sitemap-guided HTML crawl of the 10,000 experience pages — JSON-LD gives most of the same fields under ordinary crawl etiquette, capped at the head. 3) DevForum crawl for 479K prose URLs. 4) Open Cloud, which meters private and writable data but unlocks no third-party bulk reads. There is no path to the experiences themselves.
  • Cost of the head, measured: 10,000 placeId resolutions + 200 metadata multigets = 10,200 calls minimum. Serialized at the 0.35s spacing that survived probing, ~60 minutes per full refresh — cheap enough to run daily, which the 66% weekly churn demands.
  • Recrawl cadence: sitemap daily for head membership; universe metadata daily for the top decile by concurrent players, weekly otherwise; badges weekly; thumbnails only on imageId change; devforum hourly from sitemap_recent.xml.
  • Derivatives to generate: embeddings over creator descriptions, not meta text; a clone-cluster signature over title + description + screenshot hashes, since near-duplicates are the dominant corpus defect; an imputed genre label for the 32% missing genre_l2; badge-name extraction as a progression outline for content no crawler can enter.
  • Demo to build: a placeId→universeId→composite-record pipeline over the full 10,000-URL head, reporting how many distinct products those URLs represent once shared universes collapse, and what fraction are content-restricted stubs — both currently measured on only 60 URLs.

Risks to the Index

  • The Terms of Use ban the use case outright. "Restrictions of Use" (d): users may not "access the Services using any means for the purpose of using Virtual Content in connection with the training, development, or use of machine learning models or artificial intelligence." No robots.txt directive is needed to make an AI-facing index of this site a contract breach, and none exists.
  • The ML-training licence runs to Roblox only. Creators grant Roblox a "nonexclusive, royalty-free, perpetual, irrevocable, and fully sublicensable" right covering "the training of machine learning and related models"; the EU addendum adds that "Roblox reserves the right to text and data mining of the Platform." Roblox can build this index and sublicense it; a third party has no route to those rights except a negotiated one.
  • Enforcement precedent is computer-fraud, not copyright. Roblox's 10-Q describes cross-claims it filed against virtual-casino operators under the Computer Fraud and Abuse Act and California's Comprehensive Computer Data Access and Fraud Act — a theory that reaches unauthorised automated access directly, and which survived a motion to dismiss in April 2025.
  • inferred The open read tier can close without notice, and partially has. Basis: these are v1 legacy paths Roblox's docs mark deprecated in favour of key-gated Open Cloud, one sampled audio asset returns 401 where a sibling returns 200, and games/v1/games/list — a documented listing endpoint — now 404s (Probe Log).
  • inferred Sitemap membership is a ranking, so the index inherits Roblox's popularity bias. Basis: the games sitemap carries no lastmod and a sampled median of 98.5M lifetime visits with a 5.1M floor (Probe Log) — no long tail is represented, so a sitemap-only index can never answer a query about an unpopular experience.
  • Moderation retracts published records. 6.7% of sampled sitemap URLs already return stubs with creator, title and description redacted and visits zeroed. An index must treat isContentRestricted as a delete signal, not a fetch failure, or it will serve content Roblox has removed.

Inferences

  • The wall is contractual, not technical. Basis: robots.txt names no AI crawler, llms.txt/ai.txt both 404, and the API hosts serve no robots.txt at all — yet every response carries x-terms-message: Terms apply https://rblx.co/TOU. pointing at a clause banning ML use (Probe Log).
  • The games sitemap is a popularity ranking, not a census. Basis: exactly 10 children of exactly 1,000 URLs with no lastmod, and a 60-URL sample with median lifetime visits of 98.5M against a 5.1M floor (Probe Log).
  • aggregateRating is the vote tally in rating clothing. Basis: JSON-LD ratingCount 13,457,421 against votes-endpoint 12,407,895 + 1,049,525 = 13,457,420, with ratingValue 92.20 equal to the up-vote share (Probe Log).
  • External search is not a meaningful acquisition channel. Basis: a top-50 host declares 10,040 distinct URLs while its own developer forum declares 478,987 (Probe Log), and the shareholder letter attributes discovery shifts to internal RFY changes, not search.

Open Questions

  • How many experiences exist in total. Roblox publishes DAUs and hours but has never disclosed a catalogue count; third-party figures range from ~7M active to 44M+ with no primary source. Closeable only by a Roblox disclosure or a defensible universeId-space sampling study.
  • How many distinct products the 10,000 sitemap URLs represent once places sharing a universe collapse — closeable by the full-census demo above.
  • What Google actually indexes against the 10,040 declared URLs — closeable with Search Console access or a large site: sample. It decides whether the sitemap is a floor or the ceiling.
  • What governs asset-level audio access: one sampled clip returned 200 and another 401 with no visible distinguishing flag. Closeable by sampling N Creator Store audio IDs against upload date and marketplace metadata.
  • Whether any commercial data or content licence exists for third parties, and at what price — ToU (d) forbids the use, Open Cloud does not sell it, and no licensing page was found.
  • The active creator population, and whether Moments will expose any third-party API surface — neither appears in the primary filings.
